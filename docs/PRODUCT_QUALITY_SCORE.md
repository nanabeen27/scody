# Scody Product Quality Score

## 평가 범위

이 점수는 현재 프로토타입 범위의 제품 완성도를 평가한다.

평가에 포함:

- 학생·학부모·학원·관리자 핵심 사용자 여정
- 사용자 흐름의 시작·완료·후속 행동
- 뒤로가기·취소·재시도·중복 실행
- 로딩·빈 상태·오류·권한 없음
- 정보 위계와 기능 발견 가능성
- 역할·출처·권한의 명확성
- 디자인과 문구의 자연스러움
- 반응형·접근성
- 테스트 가능한 회귀 방지

평가에서 제외:

- Supabase
- 실제 인증
- 실제 결제
- 운영 배포
- 실제 데이터 영속화

단, 프로토타입의 한계를 실제 기능처럼 숨기거나 오해하게 만들면
`데이터·신뢰·권한` 항목에서 감점한다.

## 점수표

각 항목은 0~5점으로 평가한다. 0.5점 단위를 사용할 수 있다.

- 0: 존재하지 않거나 작동하지 않음
- 1: 심각하게 불완전함
- 2: 주요 허점이 여러 개 있음
- 3: 사용할 수 있지만 눈에 띄는 마찰이 있음
- 4: 전반적으로 좋고 일부 개선점이 있음
- 5: 중요 허점이 없고 코드·화면·테스트 근거가 있음

## 문제 등급

### P0

- 다른 사용자의 데이터 노출
- 데이터 손실
- 앱 또는 핵심 흐름 전체 사용 불가
- 권한 우회
- 제출 결과가 심각하게 잘못 기록됨

### P1

- 핵심 과업 완료 불가
- 학습 기록이 예고 없이 덮어써짐
- 제출·저장 성공 여부를 잘못 표시
- 사용자가 흐름에서 빠져나오거나 복구할 수 없음
- 역할이나 학습 출처를 잘못 이해하게 만드는 문제

### P2

- 핵심 행동을 찾기 어려움
- 완료 후 다음 행동이 불명확함
- 주요 빈 상태·오류 상태 누락
- 반응형·접근성의 명확한 문제
- 같은 기능이 화면마다 다르게 동작함

### P3

- 문구와 간격 개선
- 불필요한 카드와 장식
- 작은 시각적 불일치
- 핵심 행동에 영향을 주지 않는 편의 개선
